To let Jig run code

Jig runs code, shell commands and a web browser only inside an isolated Docker container, so nothing it runs can touch the rest of this computer. Without Docker, it still chats, reads the web, remembers and works with files in its own folder.

    Jig never changes this setting by itself. Each command or piece of code still asks you first.

    What Jig can do on its own

    Choose what Jig may do without asking you first. Whatever you choose, the Sentinel still checks anything that changes or sends something, and the core rules below always apply.

    Running code and using a web browser are off, because they need Docker. How to turn them on
