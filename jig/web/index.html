To let Jig run code

Jig runs code, shell commands and a web browser only inside an isolated Docker container, so nothing it runs can touch the rest of this computer. Without Docker, it still chats, reads the web, remembers and works with files in its own folder.

    Jig never changes this setting by itself. Each command or piece of code still asks you first.

    What Jig can do on its own

    Choose what Jig may do without asking you first. Whatever you choose, the Sentinel still checks anything that changes or sends something, and the core rules below always apply.

    Running code and using a web browser are off, because they need Docker. How to turn them on

      Memory and notes

      What Jig remembers about you, and the notes it writes for itself, are stored only in its database on this computer. View, change or delete any of them, at any time.

      Memories

      Tell Jig something to remember

      Jig's notes

      What Jig writes down for itself while it works, such as research findings and reminders.

      Delete all notes

      Deletes every note Jig has written from this computer. What it remembers about you stays. This can't be undone.

      Forget everything

      Deletes everything Jig keeps about you from this computer: every memory and note, every conversation, and every finished job with its results. Jig starts again knowing nothing about you. This can't be undone.

      Conversations and jobs

      Your conversations with Jig, and the jobs it has done with their results, are stored only in its database on this computer. Delete any of them, or all of them, at any time. Deleting really removes the words from Jig's database.

      Conversations

      Delete all conversations

      Deletes every conversation with Jig from this computer, with everything you and Jig said and did in it. What Jig remembers about you, its notes and its jobs stay. This can't be undone.

      Finished jobs

      Goals and tasks Jig has finished, stopped or couldn't do. A job that is still going can't be deleted: stop it first in What Jig's up to.

      Delete all finished jobs

      Deletes every finished goal and task from this computer, with its results and the questions Jig asked you about it. Jobs that are still going stay. Files Jig made in its folder stay too. This can't be undone.

      To delete everything Jig keeps about you in one go, memories and notes included, use Forget everything in Memory and notes.

      Schedules

      Jobs Jig does by itself at times you choose, such as a summary every weekday morning. Each runs in the background, and anything that needs your OK still asks you first.

      Connections

      Your own accounts that Jig can work with. Reading is just reading. Jig asks you before it sends, changes or deletes anything, and you can disconnect at any time.

      Checking your connections…

      Each account shows how to connect it, step by step. Anything you type here goes straight into Jig's vault on this computer and is never shown again. The full guide is docs/connectors-setup.md in Jig's folder.

      MCP servers

      Extra tools from a program on this computer that speaks MCP. Jig lists those tools and can call them. A tool that does not say what it does is treated as able to send, change or delete, so Jig asks you first and the safety checker reviews it.

      Jig starts the program you name. It does not use a shell. Put a token in the secret box, never in the program or the arguments. A server on the internet is not connected, so every address Jig calls stays on the allow-list.

      Sign in to Jig

      To keep Jig private, it needs a one-time sign-in on this computer. In the window where Jig is running, type jig ui and press Enter (or, if you used the Jig installer, open Jig from the Start menu). That opens Jig signed in.

      Advanced: sign in with the API token

      Paste the token from jig token show. It's swapped for a session cookie and isn't stored by the page.

      Pair this device
