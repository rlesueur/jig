\section{Conclusion and next steps}
\label{sec:conclusion}

We have set out a living benchmark for two questions that define always-on local agents---how to manage
memory over days, and how safe the agent is when unattended---together with the testbed, a fully verified
literature base and a reproducible harness that records complete provenance for every result. The safety
side is built on a deliberate constraint: it authors no attack content and measures Jig's defence layers
only against published prompt-injection benchmarks run unchanged.

The quantitative runs are queued in the overnight compute window. First is the memory comparison on
LongMemEval across the five strategies, with the standard-quantisation (Q4\_K\_M) counterpart of the agent
added to test whether quantisation changes the picture. In parallel we are building the Jig adapter for a
published injection benchmark so that attack success, utility, false positives and approvals per task can
be measured across the reviewer and read-only conditions. Each table and figure is regenerated from the
trial records as the runs complete, and others can add results to the living benchmark with one command.
