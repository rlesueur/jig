\section{Conclusion and next steps}
\label{sec:conclusion}

We have set out a living benchmark for two questions that define always-on local agents---how to manage
memory over days, and how safe the agent is when unattended---together with the testbed, a fully verified
literature base and a reproducible harness that records complete provenance for every result. The safety
side is built on a deliberate constraint: it authors no attack content and measures Jig's defence layers
only against published prompt-injection benchmarks run unchanged.

The first interim safety run shows why per-layer measurement matters: with a ternary 27B agent the
undefended attack success rate on our AgentDojo subsample was already at the floor, every success came
through the agent's text rather than a tool call, and the defence configurations differed in utility and
approval burden rather than in security. The memory pilot points the same way on cost: retrieval matched
or beat agent-curated consolidation at a fraction of its tokens, though at $n=4$ nothing is established.

Next, in order: finish the full memory run (150 trials); widen D1 to whole suites, more seeds and the
standard-quantisation agent so that the undefended attack rate is measurable; run the Qwen reviewer when
VRAM allows; and add InjecAgent once its licence is confirmed. Each table and figure is regenerated from
the trial records as the runs complete, and others can add results to the living benchmark with one
command.
